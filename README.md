# Throwlab Fullstack Project

This repository contains the source code for a biomechanics video analysis platform. It consists of two main applications:

- **backend/**: A FastAPI service for receiving uploaded videos, transcoding them via ffmpeg, extracting key frames, and returning analysis results.
- **frontend/**: A Next.js (React) web application for uploading videos, displaying results, and visualizing phase metrics.

## Getting started

1. See `backend/requirements.txt` for Python dependencies and `backend/railway.json` for Railway deployment configuration.
2. See `frontend/package.json` for Node dependencies and `frontend/vercel.json` for Vercel deployment configuration.
3. Follow the deployment instructions in `DEPLOY.md` to run and deploy the project.
